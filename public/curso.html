MÓDULO 01 · BANCO DE DADOS

Comandos que todo desenvolvedor deveria saber

Aprenda os fundamentos do MongoDB e pratique operações essenciais com documentos.

01. Conhecendo o MongoDB

O MongoDB é um banco de dados NoSQL orientado a documentos. Em vez de tabelas e linhas tradicionais, ele organiza informações em coleções e documentos BSON, semelhantes ao JSON.

show dbs

Lista os bancos de dados disponíveis no servidor.

02. Selecionando um banco

use minha_aplicacao

Seleciona o banco de dados. Se ele ainda não existir, será criado quando você armazenar dados nele.

03. Inserindo documentos

db.usuarios.insertOne({
  nome: "Ana",
  idade: 25,
  ativo: true
})

O método insertOne() insere um documento em uma coleção. Se necessário, a coleção será criada automaticamente.

04. Consultando documentos

db.usuarios.find()
db.usuarios.find({ idade: { $gt: 18 } })

O primeiro comando retorna os documentos da coleção. O segundo filtra usuários com idade superior a 18 anos.

05. Atualizando documentos

db.usuarios.updateOne(
  { nome: "Ana" },
  { $set: { ativo: false } }
)

O updateOne() atualiza o primeiro documento que corresponde ao filtro.

06. Excluindo documentos

db.usuarios.deleteOne({ nome: "Ana" })

O deleteOne() exclui o primeiro documento correspondente. Sempre confira o filtro antes de executar exclusões.

07. Contando documentos

db.usuarios.countDocuments()

Retorna a quantidade de documentos da coleção. Você também pode passar um filtro para contar apenas os documentos que correspondem a ele.
